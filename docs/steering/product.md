# Product Overview

gh-pm is a GitHub CLI extension that brings project management capabilities directly to the command line, integrating seamlessly with GitHub Projects (v2) and Issues.

## Core Capabilities

- **Issue Lifecycle Management** - Create, view, move, and track issues with project metadata (Status, Priority) directly from CLI
- **Project Integration** - Connect repository issues to GitHub Projects v2 boards with intelligent intake and filtering
- **Task Decomposition** - Split complex issues into sub-issues using GitHub's native hierarchy, with duplicate detection and inheritance
- **Bulk Operations** - Triage, filter, and update multiple issues at once using configurable rules and queries
- **CLI-First Experience** - Full `gh issue list` compatibility with project-specific extensions, multiple output formats, and web integration

## Target Use Cases

- **Project managers** streamlining issue triage and prioritization without leaving the terminal
- **Development teams** needing quick issue creation and status updates during workflow
- **Technical leads** breaking down large issues into actionable sub-tasks
- **DevOps/CI** automating project field updates and bulk operations via scripts

## Value Proposition

gh-pm eliminates the context-switching between terminal and web UI by bringing GitHub Projects v2 capabilities to the CLI. Unlike basic `gh issue` commands, it provides:

- Project-aware filtering and queries (status, priority, custom fields)
- Automatic metadata caching for fast operations
- Smart issue intake with duplicate prevention
- Native sub-issue relationships with inheritance
- Configuration-driven workflows for consistent team practices
